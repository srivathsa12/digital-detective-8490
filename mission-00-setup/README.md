# Mission 0 — Repository and workspace setup

## Objective
My task was to create a public GitHub repository with the right name, set up a folder for every mission, and push my first commit.

## Work completed
Created the project folder digital-detective-8490 on my Desktop with 9 mission folders and an evidence folder. Each mission folder has its own README.md, mission-05-numbers-data also has number_converter.py, and evidence has a .gitkeep file. Wrote the root README with a mission index and pushed the work to GitHub.

## Commands used
Tools: Python 3.13.14, Git 2.55.0, Terminal (zsh), VS Code

I used mkdir -p to create the folders, touch to create the empty files, and ls -R to check the structure. I also used Git commands to commit and push my work.

## My understanding
A repository is a project folder that Git tracks, so every change is saved in a history. GitHub keeps an online copy of it. I made one folder for each mission so that my work stays separate, each mission has its own README and commit, and anyone reading the repository can follow the missions in order.

## Difficulties faced
My first push to GitHub was rejected. The old repository with the same name still existed, and then the new one had an automatic README that my computer did not have.

## How I resolved them
I read the error message, deleted the old repository and made a new empty one without a README, and then the push worked. I also used Google and Claude to understand the error.
