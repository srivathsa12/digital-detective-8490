## My Learning
- A computer works with input, process, storage and output.
- The Terminal lets me move around and manage files using commands.
- Computers use binary (0s and 1s) to store data.
- Git saves the history of my work.

## Topics explored
- Input, processing, output and storage (IPOS), hardware and software
- Terminal commands, flags and pipes
- Operating system, processes, paths and permissions
- Compilers and interpreters
- Number systems (binary, decimal, hexadecimal) and text encoding
- Git, branches and Pull Requests
- Computer networks, DNS and how a website loads

## How to run the number converter
1. Open Terminal in the project folder.
2. Move into the mission folder: cd mission-05-numbers-data
3. Run the program: python3 number_converter.py
4. Type a positive whole number when it asks.
5. The program prints the binary and hexadecimal results.
