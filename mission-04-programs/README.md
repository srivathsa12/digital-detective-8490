### Compiler and interpreter comparison
| Point | Compiler | Interpreter |
|---|---|---|
| When translation or execution happens | Translates the whole program before it runs | Translates and runs the code while the program is running, line by line |
| Typical output | Yes, a separate file (like an .exe) that you can run later | No separate file, it just runs the code straight away |
| One example | C (usually compiled) | Python (usually interpreted) |
| One advantage | Speed, the finished file runs fast | Convenience, you can edit and run again right away |

Difference in my own words:
A compiler translates the whole program first, before anything runs, and gives you a separate file that you can run again and again. An interpreter translates the code while it is running, so you don't get a separate file, you just see the result. Because of this, compiled programs are usually faster, but interpreted ones are easier to test and change quickly. The trade off is speed against convenience.

## My understanding
