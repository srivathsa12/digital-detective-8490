# Mission 1 — Know your computer

## Task / objective
Input is gennerally given through the pyhsical devices such as keyboard, mouse, etc.. . It takes raw data and instruction and feed it to the computer. The Computer has it's main processing unit called Central Processing Unit(CPU) takes input and process it, perform operations and do the main work as a human brain. Output is result after the process in CPU. Storage is used to store data for the futture usage. Like RAM, ROM, SSD,..

## Work completed

### IPOS for one activity
Activity I chose: Recording my voice and playing it back on my MacBook

| Stage | What happens in my example? | Hardware / component |
|---|---|---|
| Input | I speak and the microphone picks up the sound| Microphone|
| Processing | The processor turns the sound into digital data and compresses it, using memory while it works| CPU, RAM|
| Output | When I press play, the sound comes out| Speaker|
| Storage | The recording is saved as an audio file so I can play it later| SSD|

How the activity moves from input to output and storage: The microphone captures my voice as input. The CPU processes it by converting it to digital data. The file is saved to storage, and when I press play, the CPU reads it back and sends it to the speaker as output.
